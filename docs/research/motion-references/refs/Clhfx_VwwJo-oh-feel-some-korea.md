## 가져올 규칙

- **형태 변환:** 원 → 소용돌이 → 반복 패턴 → 복도 축 → 항로 선처럼 한 장면의 형태를 다음 장면의 구조로 재사용한다.
- **공통 축:** 화면 중앙, 원근 통로, 회전 중심을 장면마다 유지해 장소가 바뀌어도 한 여정으로 느끼게 한다.
- **카메라 연속성:** 단순 하드 컷보다 확대·회전·터널 진입·밝기 변화가 컷을 가로질러 다음 소재를 드러낸다.
- **반복과 변주:** 같은 곡선·문양·대칭을 색·재질·스케일만 바꿔 반복한다.
- **장식의 기능화:** 원·선·패턴이 빈 공간을 채우는 장식이 아니라 중심축·통로·변형의 원인이 된다.
- **텍스트 절제:** 작품 정보는 화면을 지배하지 않는다. 화면의 실제 의미는 움직이는 형태와 공간이 전달한다.
- **끝의 회수:** 마지막 사인이 첫 장면의 공간감과 연결돼 전체 영상을 하나의 작품으로 닫는다.

## Enigma 프로젝트에 적용할 번역

`A→A 불가능`의 화살표를 단순 제목으로 두지 않고, 계속 변하는 주인공으로 만든다.

```text
A→A 규칙
  → 화살표 선이 rotor의 회전축이 됨
  → rotor의 반복 홈 중 하나가 벌어진 빈틈이 됨
  → 빈틈이 문자 대응선으로 펼쳐짐
  → 대응선이 crib 문자열을 정렬함
  → 문자열의 모순이 후보 블록을 지움
  → 살아남은 선이 Bombe 다이얼의 회전축이 됨
  → 남은 선이 지도상의 안전 항로가 됨
  → 항로의 끝 화살표가 다시 A→A로 돌아옴
```

이 레퍼런스를 스타일 복제로 사용하지 않는다. 최종 영상에는 원본 영상·음악·사인·장면을 넣지 않고, 위의 형태·축·변환 원리만 새로 만든 Enigma 도식과 기존 분위기 소재에 번역한다.
