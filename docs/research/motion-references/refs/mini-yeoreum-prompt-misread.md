## 한 줄 요약

노트북 앞 사용자의 지시와 카페 로맨스의 엉뚱한 결과를 교차하며, 수정을 할수록 오해가 인물·행동·장소로 번지는 약 1분짜리 코미디.

작성자는 중국의 유사 AI 영상을 보고 한국 버전을 만들었다고 설명한다. 선행 작품의 출처는 이번에 확인하지 않았다. 원문에는 `Powered by @zcre.co.kr` 표기가 있지만 모델이나 구체적인 제작 경로의 증거는 아니다.

## 가져올 것

- **요청 → 의외의 결과 → 반응 → 수정의 반복.** 다음 컷 전에 의도를 알려 관객이 오류를 바로 알아보게 한다. 결과를 먼저 설명하는 자막을 붙여 반전을 소모하지 않는다.
- **오류를 이어 붙인다.** 커피가 머리에 쏟아짐 → 머리 감기 → 역할 반전 → 카페 안 샴푸대. 앞의 이상한 결과가 다음 장면의 소재로 남으므로 무작위 개그보다 흐름이 생긴다.
- **익숙한 구도를 반복한다.** 방의 노트북 사용자가 기준 화면이고 카페·미용실이 결과 화면이다. 따뜻한 조명, 같은 인물·의상, 반복되는 책상 구도로 복잡한 설명을 줄인다.
- **한 번에 하나의 조건을 비튼다.** 문을 여는 힘, 고개의 방향, 앉는 위치, 커피를 붓는 대상, 되돌릴 대상처럼 어긋난 지점을 읽기 쉽게 만든다.
- **사용자 반응을 편집의 마침표로 쓴다.** 손짓·표정·자막이 잘못된 결과의 의미를 확정하고 다음 요청으로 넘어간다. 끝에서는 노트북 닫기 하나로 결론을 낸다.
- **우리 제작용 제안:** 일상 과제 하나를 고르고 3–4회의 수정으로 행동→관계→장소 순서로 오해를 확장한다. 결과 컷은 대본으로 설계해 제작하고 인물·의상·조명 참조를 고정한다. 실제 AI의 우연한 오류를 기다릴 필요는 없다. 이 방법은 재현 제안이며 원작 제작 과정의 확인 결과가 아니다.

인용 예: `ref: mini-yeoreum-prompt-misread 36–57초 앞선 오류를 남긴 채 수정 조건 하나만 반영하는 연쇄 개그`.

## 피할 것

- 서로 무관한 실패 장면을 나열해 수정과 결과 사이의 인과관계를 끊는 것.
- 관객이 요청을 읽기 전에 반전을 보여 주거나, 반응을 길게 끌어 반복을 느리게 만드는 것.
- 재현 영상의 연출된 오류를 특정 모델의 실제 성능 사례라고 제시하는 것. 이 작품만으로 모델 성능은 판단할 수 없다.
- 작은 한영 자막을 세로판에 그대로 축소. 우리 버전은 시청 환경에 맞는 자막 크기와 언어 우선순위를 정한다.
- 원작의 인물·대사·장면을 통째로 복제하는 것. 반복 구조를 다른 과제와 새로운 인물에 적용한다.

## 확인 못 한 것

- 실제 생성 도구·모델·프롬프트·재시도 횟수·편집 원본. 장면 속 실패가 자연 발생인지 의도적인 재현인지도 미확인.
- 음악·효과음·발성·립싱크·사운드 타이밍. 오디오 스트림은 있지만 청취·전사는 수행하지 않았다.
- 모든 프레임의 동작과 정확한 컷 경계. 전체 약 1.49초 간격, 후반 약 1.05초 간격으로 관찰했다.
- 선행 중국 영상과 원작 소재·음악의 권리 관계.
