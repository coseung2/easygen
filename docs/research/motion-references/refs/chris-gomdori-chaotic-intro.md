## 한 줄 요약

경력·개발·서비스·후기·성과를 능력치·퀘스트·아이템·NPC 대사·보스전으로 번역해, 한 사람의 이력을 플레이 기록처럼 보여주는 픽셀 RPG 자기소개.

사용자 선호: 공유하면서 “아주 맘에 드네”라고 평가한 레퍼런스. 향후 유쾌한 자기소개·개발자 소개·서비스 소개의 우선 참고 후보로 둔다. 아래 활용 제안은 분석자의 해석이며 사용자가 특정 요소를 따로 승인한 것은 아니다.

화면에 나오는 스타 수·벤치마크 순위·업무 절감 수치·수상·기관 목록·후기는 **영상 내부 주장**이다. 이번 분석에서 사실 여부나 인용 권한을 검증하지 않았다.

## 가져올 것

- **한 가지 세계관으로 끝까지 설명하기.** 경력=STATUS, 노력=EXP, 개발 과정=퀘스트, 서비스=아이템, 후기=NPC 대사, 문제=보스, 성과=업적. 화면마다 다른 유행 효과를 고르는 대신 정보의 역할부터 게임 요소에 대응시킨다.
- **약점에서 시작하는 주인공.** 처음의 코딩 0·대응 실패가 뒤의 개발 성과와 대비된다. 자기자랑의 나열보다 전후 변화가 기억에 남는다는 해석이다.
- **실제 화면도 게임 안에 넣기.** 제품 캡처·후기·지도는 획득 창이나 대화창에 담고, 동일한 테두리·남색 패널·노란 제목을 반복한다.
- **제품을 마지막 행동에 다시 쓰기.** 앞에서 얻은 서비스가 보스전의 명령 목록으로 돌아온다. 곰도 시작·마을·전투·크레딧을 잇는 동료 모티프다.
- **진지한 정보와 작은 농담을 교대.** 거대한 보스에 -1, 효과 없는 명령, 응원처럼 웃음은 게임의 피드백에서 나온다. 제품 기능과 관련된 농담을 배치한다.
- **변형보다 피드백.** 프레임에서 확인되는 메뉴 선택, 글자 누적, 수치 변화, 히트 플래시, 입자, 카드 확대처럼 단순한 동작을 사건에 맞춘다. 상세 이징·음악 동기화는 미확인이다.
- **우리 제작에 적용하는 제안:** 작은 주인공 1명과 동료 1명, 대화창·능력치 창·아이템 창·보스 화면을 공통 소재로 만들고 내용만 교체한다. 한글·수치·실제 UI는 편집 가능한 레이어로 두고 AE 또는 코드로 구성할 수 있다. 이는 재현 제안이며 원작의 구현 도구를 확인한 결과는 아니다.

재사용 브리프 예: `ref: chris-gomdori-chaotic-intro 14–34초 문제→첫 시도→성장, 82–95초 획득한 도구로 문제에 재도전`. 대상 서비스에 맞는 독자적인 캐릭터·문구·음악으로 새로 만든다.

## 피할 것

- 픽셀 외형만 붙이고 이력 목록을 그대로 읽는 구성. 각 정보가 다음 행동의 이유나 결과가 되게 한다.
- 16:9 화면을 세로로 단순 축소. 이 영상의 작은 후기·표·기관 이름은 폰에서 읽기 부담이 크므로 세로판은 정보량과 배치를 다시 설계한다.
- 수치와 프로젝트를 한꺼번에 쏟는 구성. 짧은 홍보물로 옮길 때는 대표 도구와 한 가지 문제를 고른다.
- 본편 캐릭터·게임 연상 요소·후기 캡처·음악을 그대로 재사용하거나 확인되지 않은 실적을 우리 사실처럼 인용하는 것.

## 확인 못 한 것

- 음악 장르·곡명·효과음·내레이션 유무·비트와 컷의 동기화. 오디오 스트림의 존재만 확인했고 청취·전사하지 않았다.
- 제작 코드, 사용 라이브러리, AE 사용 여부, 실제 모델 버전, 수작업 수정 범위, 폰트와 소재 라이선스.
- 모든 프레임의 내용과 정확한 컷 경계. 전체는 약 2.94초 간격, 후반은 약 1.15초 간격으로 표본 확인했다.
- 같은 작성자가 댓글에 올린 카툰3D 버전은 별도 작품이므로 이번 분석에는 포함하지 않았다.
