# 재사용 기법

여러 레퍼런스에서 반복 확인된 연출 기법이다. 수치가 있는 항목은 원영상 측정값과 초안용 제안을 구분해 적었다.

## 훅과 기억

| 기법 | 방법 | 근거 |
| --- | --- | --- |
| 퀴즈형 훅 | 첫 2초에 질문을 던지고 정답을 브랜드로 만든다 | [NEPDA 넾](../refs/nepda-neop.md) 0–7초 |
| 다짐 → 반전 콩트 | 익숙한 다짐을 즉시 무너뜨려 공감을 얻고 제품을 해결책으로 제시 | [신한](../refs/shinhan-simple-plan.md) 3–19초 |
| 이름 말장난 | 모델명·브랜드 약칭·상품명을 혜택 단어와 겹친다 (수북즈→수북하게, 넾→넓다, Simple→심플하게) | [신한](../refs/shinhan-simple-plan.md), [NEPDA](../refs/nepda-neop.md) |
| 루프 엔딩 | 마지막 프레임을 첫 장면으로 되돌려 쇼츠 반복 재생 유도 | [NEPDA](../refs/nepda-neop.md) 18.5–20초 |
| 모티프 회수 | 앞 장면의 상징을 뒤에서 변주해 재등장 | [Sunbeam](../refs/qaYO4A8Zf5E-seven-sunbeam.md) |

| 기법 | 방법 | 근거 |

| 컷 밀도 = 메시지 강도 | 가장 과장된 메시지 구간에 컷을 몰아 넣는다 (7–11초에 약 20회) | [NEPDA](../refs/nepda-neop.md) |
| 대사 리듬이 편집을 대신 | 컷 4회만으로 30초 유지 | [신한](../refs/shinhan-simple-plan.md) |
| 움직임과 정착의 교대 | 빠른 타이포 뒤 읽는 구간, 마지막 로고 유지 | [LangEase](../refs/SgmuplXU2iY-langease.md), [Lovable](../refs/xDwR1_vrIg8-lovable-2.md) |

초안용 시간 제안(30fps, 원영상 측정값 아님): 속성 변화 6–12f, 주 전환 12–24f, 카드 간 지연 2–4f, 결과 정착 0.8–1.5초, 로고 유지 1.5–2.5초.

## 게임 형식의 서사 (단일 레퍼런스 관찰)

- 정보의 역할을 게임 요소에 대응: 이력→능력치, 노력→EXP, 서비스→아이템, 후기→NPC 대사. [딴짓하는 류주임](../refs/chris-gomdori-chaotic-intro.md) 8–72초.
- 얻은 도구를 마지막 문제 해결에 다시 사용: 앞서 소개한 서비스가 전투 명령으로 돌아와 기능과 이야기를 연결한다. 같은 카드 82–95초.
- 작은 피드백으로 농담 만들기: 거대 보스에 피해 -1, 동료 응원, 보스 도주. 수치·반응 자체를 웃음으로 쓴다. 같은 카드 82–95초.

## 수정과 오해의 연쇄 (단일 레퍼런스 관찰)

- 요청→결과→반응→수정을 반복하고, 의도는 결과를 보여 주기 전에 전달한다. [말 잘 듣는 AI](../refs/mini-yeoreum-prompt-misread.md).
- 이전 오류의 소재를 다음 오류에도 유지: 머리에 커피→머리 감기→역할 교환→카페 안 샴푸대. 수정 조건 하나만 바뀌고 엉뚱한 행동은 남는 구조. 같은 카드 36–57초.
- 반복되는 사용자 화면을 기준점으로 쓰고, 마지막은 노트북을 닫는 행동으로 끝낸다. 실제 모델의 실패 기록과 연출된 코미디를 혼동하지 않는다.

## UI 공간 확장과 복귀 (단일 레퍼런스 관찰)

- 기준 위젯을 유지하면서 주변 배경을 픽셀 경계로 펼쳐 상세 작업 공간을 공개한다. [캘린더 픽셀 트랜지션](../refs/gasket-love-calendar-pixel.md) 3.5–4.7초.
- 제목→위치→메모처럼 현재 입력 필드를 따라 확대·이동하고, 완료 버튼에서는 다시 전체 맥락을 보여 준다. 같은 카드 5–12초.
- 종료 시 같은 위젯 구도로 돌아오되 선택 범위 등 변경 상태는 남긴다. 구도 회수와 완전한 무봉제 루프를 구분한다. 같은 카드 12–16초.

## 상황 속 카피와 전후 비교

- 읽는 행동을 행사 공개로 연결: 시력표의 글자·숫자를 읽는 상황에서 행사 날짜를 도출하고 혜택을 공개한다. [G마켓](../refs/gmarket-eye-test-sale.md) 4–19초. 말장난의 정확한 음성은 미확인.
- 비교 기준→변화 후 쇼릴: 단순한 도형 움직임을 먼저 보여 주고 제한 팔레트의 타이포·콜라주로 전환한다. [강현 AE](../refs/goodie-land-ae-before-after.md) 0–15초. 학습 효과에 관한 홍보 주장은 검증하지 않음.
- 같은 소재군을 크기·중첩·반복으로 변주: 꽃·인물·글자를 고정된 팔레트 안에서 재배치한다. 같은 카드 10–27초.

## 반복해서 나온 약점

- 구체적 혜택 숫자 부재 → 과장 형용사가 추상적으로 남음 ([NEPDA](../refs/nepda-neop.md)).
- 법적 고지·작은 설계 문구가 핵심 메시지와 화면을 다툼 ([신한](../refs/shinhan-simple-plan.md), [NEPDA](../refs/nepda-neop.md)).
