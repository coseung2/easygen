# 작업용 스타일 분류

레퍼런스를 다시 찾고 제작 방향을 고르기 위한 내부 분류다. 시장의 공인 명칭이 아니다. 각 행의 근거 카드에 타임코드와 원자료가 있다.

스타일 이름 하나로 지시를 끝내지 않는다. 색·재질·타이포·움직임·금지 요소 같은 관찰 가능한 규칙으로 바꿔서 지시한다.

## 제품·광고 중심 스타일

추가 관찰 — **실사풍 AI 메타 코미디**: 따뜻한 방의 사용자 반응과 같은 인물의 생성 결과를 교차한다. 요청의 한 조건을 비틀고, 수정할수록 직전 오류를 이어받아 상황을 확대한다. 독립된 개그보다 대본의 인과관계가 우선이다. 제작 경로 제안은 인물 참조를 고정한 장면별 생성 + 반응 컷 편집이며 원작 모델은 미확인. [말 잘 듣는 AI](../refs/mini-yeoreum-prompt-misread.md) 참조.

추가 관찰 — **픽셀 RPG 자기소개**: 남색 패널·얇은 테두리·노란 제목·작은 주인공과 동료를 반복하고, 이력과 서비스를 능력치→퀘스트→아이템→NPC 후기→보스전→업적으로 연결한다. 실제 제품 화면도 같은 창 안에 넣는다. 재현 경로 제안은 독자 픽셀 소재 + AE·코드이며 원작 도구는 미확인. [딴짓하는 류주임](../refs/chris-gomdori-chaotic-intro.md) 참조.
