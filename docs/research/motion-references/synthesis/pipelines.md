# 제작 파이프라인

관찰한 영상에서 나온 제작 경로 세 가지와 우리 기본 경로 제안이다. 우리 환경에서 시간·비용을 측정한 결과는 아니다.

| 경로 | 구성 | 적합한 작업 | 남는 수정 가능성 | 주의점 | 근거 |
| --- | --- | --- | --- | --- | --- |
| 영상 생성 | 브리프 → 연출 지시서 → 참조 → 영상 모델 → 후보 선택 | 감각적 짧은 광고, 캐릭터 동작, 유기적 변화 | 프롬프트·참조·설정 | 글자 하나 수정에도 재생성이 필요할 수 있음 | [디자인하는AI](../refs/9uQVYIaYIeg-design-ai-2d-motion.md) |
| 이미지 + 코드 | 브리프 → 분리 이미지·포즈 생성 → 정렬 → 코드 → 렌더 | 종이·디오라마·지도·반복 모션·타이포 | 소재·장면 명세·코드 | 좌표·앵커·알파가 불안정하면 떨림 | [원카AI](../refs/a3HPd9wsROU-wonka-vox-paper.md), [쌩초](../refs/Y7l9svE-ymQ-ssaengcho-code-motion.md) |
| AI + AE | 브리프 → 소재 → 컴포지션·텍스트·키프레임 → 프리뷰 → 부분 수정 | 한글 중심, 로고, 브랜드·제품 UI, 혼합 합성 | AE 네이티브 레이어 | 버전·폰트·플러그인·연결 호환성 | [코드깎는노인](../refs/kc5WFHtChdc-codeoldman-vibe-ae.md) |

## 기본 경로

```text
브리프 · 정확한 카피 · 확인된 사실
    ↓
레퍼런스 분석 → 스타일 기준 + 모션 기준   (refs/ 카드에서 선택)
    ↓
샷 계획 + 음악·나레이션 주요 시점
    ↓
핵심 화면 3–5장 → 저해상도 애니매틱
    ↓
샷별 경로 선택
    ├─ 글자·로고·UI·도형 → AE 또는 코드
    ├─ 종이·지도·디오라마 → 분리 이미지 + 코드·AE
    └─ 실사·유기적 동작 → 영상 생성
    ↓
통합 타임라인 · 사운드 → 부분 수정 → MP4 + 편집 원본 보존
```

## 원칙

- 정확한 문구·숫자·로고·UI는 편집 가능한 레이어로 만든다. 생성 모델은 필요한 샷에만 쓴다.
- 참조는 스타일·정체성·구도·모션·시작/끝 프레임으로 역할을 나누고, 실행 도구가 그 입력을 실제로 받는지 확인한다.
- 수정은 `샷 · 시간 구간 · 대상 요소 · 변경 속성 · 보존 대상`으로 지정한다.
- 비용은 기획·소재 생성·재생성·렌더·수정 시간을 나눠 기록한다.
