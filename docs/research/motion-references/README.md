## 카드 작성 규칙

- 분석 방법 칸에는 실제로 수행한 것만 적는다 (자막·프레임·OCR·오디오 등).
- AI 제작 여부는 확인된 경우에만 "확인됨"으로 적는다. AI 제품 광고와 AI로 만든 광고를 구분한다.
- 광고 속 성능·수치 주장은 검증된 사실로 옮기지 않는다.
- 확인하지 못한 것은 "확인 못 한 것"에 남긴다.
