# Windows 체크아웃의 매니페스트 해시 불일치

- 일시: 2026-10-06, Asia/Seoul.
- 증상·영향: 공개 워크플로우 정리용 별도 작업 공간에서 `pipelines/seal.py`가 변경하지 않은 템플릿·프롬프트 파일까지 해시 변경으로 판정했다. 원격 생성이나 기존 앱 작업본에는 적용하지 않았다.
- 확인: `pipelines/_shared/motionkit.py`의 작업본은 CRLF였고, LF로 정규화한 SHA-256은 Git 원본 및 기존 매니페스트와 일치했다. 원인은 Windows 체크아웃의 줄바꿈 변환이다.
- 대응: 해시 검증 대상 텍스트의 LF를 `.gitattributes`에 고정하고 별도 작업본을 정규화한 뒤 해시를 다시 계산했다. 의도한 후보 프롬프트 변경만 새 해시로 남긴다.
- 복구 검증: 작업본과 `core.autocrlf=true` 새 클론 모두 `python pipelines/seal.py --check` 통과. 새 클론의 호출기 테스트 12개와 과거 워크플로우 스냅샷 12개 해시 검사도 통과했다.
- 예방: 해시 대상의 원시 바이트를 OS별 줄바꿈에 따라 재봉인하지 않는다. 기존 결과물이나 모델 가중치에는 손대지 않는다.
