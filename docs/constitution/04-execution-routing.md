# 제4조 실행과 비용

앱 없는 기본 실행은 사용자의 Modal 워크스페이스에 배포된 GPU 함수를 Python SDK로 호출한다. 앱이나 After Effects 설치를 실행 조건으로 추가하지 않는다.

유료 생성 전 사용자가 승인한 생성 종류·입력·횟수와 예상 비용 또는 GPU 시간을 확인한다. 이미 승인된 범위는 반복 확인하지 않는다. 추정이 불가능하면 모른다고 표시하며 금액을 지어내지 않는다. H3 라이선스 취득은 이미 완료된 전제이므로 다시 묻지 않는다.

- 로컬 `prepare`와 단위 검사는 GPU를 사용하지 않는다.
- `submit`은 유료 원격 실행이다. `health`와 `validate_graph`도 GPU 컨테이너를 시작할 수 있다.
- 대기 timeout은 원격 실패가 아니다. 호출 ID를 저장하고 같은 호출을 조회한다.
- 접수가 불확실한 실행을 자동 재제출하지 않는다. 실패 후 새 생성은 승인 범위를 확인한다.
- 취소 요청을 즉시 정지·과금 종료의 증거로 보고하지 않는다.
- SDK 결과의 실행 시간과 실제 청구 GPU 시간을 구분한다. 배포·다운로드·파일 검증을 실제 추론 성공과 혼동하지 않는다.
