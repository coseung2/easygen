# 제4조 실행 경로 선택

모든 샷과 소재는 만들기 전에 실행 경로를 정한다. 원칙은 **로컬이 기본이고, 새 픽셀이나 새 소리를 만들어야 할 때만 위 단계로 올라간다**는 것이다.

## 1. 네 단계

| 단계 | 실행 도구 | 맡는 일 | 비용·특성 | 매니페스트 `engine` |
| --- | --- | --- | --- | --- |
| 1 로컬 코드 | Python, FFmpeg, PIL | 타이포, 도형, 그래프, 컷 편집, 비트 동기화, 자막, 합성 | 무료. 같은 입력이면 같은 결과. 즉시 재실행 | `local-python` `local-ffmpeg` |
| 2 모션 도구 | After Effects, Autograph, Cavalry | 복잡한 키프레임, 텍스트 애니메이터, 입체 레이어, 브랜드 모션 | 라이선스 보유 시 무료. 편집 가능한 프로젝트가 남음 | `ae-script` `autograph` `cavalry` |
| 3 외부 생성 API | 이미지 생성 API 등 | 캐릭터, 질감, 배경 같은 새 정지 소재 | 호출마다 유료. 결과가 매번 다름 | `external-api` |
| 4 Modal GPU | H3 영상, YuE2 음악 | 실사 느낌, 자연스러운 동작, 카메라 이동, 새 음악 | 유료. 콜드 스타트 대기. 결과가 매번 다름 | `modal-comfyui` `modal-python` |

## 2. 판단 순서

샷마다 아래 질문을 차례로 던지고, 처음 "예"가 나온 곳에서 멈춘다.

1. **정확해야 하는가?** 문구, 숫자, 로고, UI, 지도 데이터라면 1·2단계에서 만든다. 생성 모델에 맡기지 않는다.
2. **기존 소재를 배치·변형하면 되는가?** 된다면 1·2단계에서 끝낸다. 기존 소재에는 이미 생성해 둔 클립(`F:\modal-gui\h3-clips`), 이미지도 들어간다. 음악은 이 질문에서 제외하고 아래 음악 규칙을 따른다.
3. **새 정지 소재가 필요한가?** 3단계.
4. **새 움직임이나 새 음악이 필요한가?** 4단계.

### 음악

음악은 기존 곡 재사용을 우선하지 않는다. 작품마다 브리프(분위기, 템포, 용도, 공개 범위)에 맞춰 새로 정한다.

- 기본은 이 작품을 위한 새 음악이다(4단계, §3 승인).
- 사용자가 곡을 지정하면 그 곡을 쓴다.
- 기존 생성 곡(`F:\modal-gui\series\music-beds`, `F:\modal-gui\music`)은 사용자가 고르거나, 브리프에 맞는지 들어서 확인하고 용도에 맞는 라이선스인지 확인한 경우에만 후보로 제시한다. 비용이 없다는 이유만으로 고르지 않는다.

1단계와 2단계 중에서는 결과가 어디서 수정될지로 고른다. 사용자가 AE에서 직접 손볼 예정이면 2단계, 코드로 반복 생성하거나 무인 렌더가 필요하면 1단계다.

한 샷을 여러 단계로 나눠도 된다. 예를 들어 배경 움직임은 4단계로 만들고, 그 위의 글자는 1·2단계에서 합성한다.

## 3. 유료 단계 승인

- 3·4단계를 실행하기 전에 샷 계획을 보여주고 승인을 받는다. 샷별 단계, 도구, 예상 호출 수, 예상 비용 또는 GPU 시간을 함께 보여준다.
- 예상 비용을 모르면 "모름"이라고 쓴다. 금액을 지어내지 않는다.
- 승인받은 범위를 넘는 재생성은 다시 승인을 받는다. 실패했다고 자동으로 무한 재시도하지 않는다.
- 1·2단계는 승인 없이 진행할 수 있다.

## 4. 기록

결과마다 어느 단계, 어느 도구, 어느 파이프라인 버전으로 만들었는지 남긴다(제3조 §7). 유료 단계는 실제 청구액과 추정치를 구분해 기록한다.

## 5. 현재 미준수 사항

- 3단계에 해당하는 이미지 생성 API가 앱 코드에 아직 연결돼 있지 않다. 지금은 에이전트가 쓸 수 있는 이미지 생성 도구를 쓰고, 결과를 소재로 가져온다.
- `pipelines/` 레지스트리가 없어서 `engine` 값은 아직 어디에도 기록되지 않는다(제3조 §8).
