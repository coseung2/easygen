# 제5조 개발 범위

이 저장소는 재사용 가능한 원격 워크플로우·JSON·호출 코드와 선택적 앱을 관리한다.

| 범위 | 위치 |
| --- | --- |
| 원격 실행·배포 | `modal/` |
| H3 그래프 원본과 변환 | `worker/graphs/`, `worker/h3_graph.py` |
| 앱 없는 직접 호출 | `tools/modal_workflow.py` |
| 선택적 앱 | `src/`, `src-tauri/` 및 해당 어댑터 |
| 기존 앱용 템플릿·프롬프트 | `pipelines/`, `prompts/` |

영상 제작 산출물 관리, 레퍼런스 수집·분석, 창작 지침, 개별 영상·에피소드 제작 파이프라인은 다른 프로젝트로 완전히 분리했다. 이 저장소에 Lab 폴더·제작 규칙을 다시 만들거나 외부 이용자에게 별도 프로젝트 복제를 요구하지 않는다.

기존 워크플로우를 쓰는 이용자에게 앱 설치, Lab 제작 절차 또는 새 파이프라인 승격을 요구하지 않는다. 기존 앱용 템플릿과 공통 렌더 엔진은 실제 앱 사용처가 있으므로 개별 작품 제작 파일과 구분한다.

## 개정 이력

- 2026-09-27 제정.
- 2026-10-06 (Asia/Seoul): 분리 완료된 제작 관리·레퍼런스·Lab 승격 절차를 제거하고 워크플로우와 선택적 앱 개발 범위만 남김.
