# 제3조 버전과 실행 근거

변경된 원격 코드와 그래프를 구분할 수 있도록 Git 커밋, 배포 이름·버전, 실제 사용한 API 그래프와 호출 ID를 기록한다. Modal 배포의 v번호는 파이프라인 의미 버전과 다르다. 기록되지 않은 모델 revision·해시나 새 계정 재현을 검증된 것처럼 표시하지 않는다.

현재 H3 직접 실행은 `worker/graphs/` 원본을 `worker/h3_graph.py`로 변환한다. `workflows/comfyui/snapshots/`는 과거 스냅샷이므로 현재 배포와 동일하다고 가정하지 않는다. YuE2는 Python 파이프라인이며 ComfyUI JSON 버전을 만들지 않는다.

호출 도구는 저장소 밖 실행 폴더에 요청, H3 API 그래프, 호출 상태와 결과 해시를 남긴다. 배포 이름 조회는 기본적으로 현재 배포를 사용하므로 생성 전후 배포 변경을 피하고 `modal app history`를 별도로 기록한다. Git 커밋만으로 외부 모델 가중치·이미지의 완전한 재현을 보장하지 않는다.

기존 `pipelines/`, `prompts/`의 버전 정의를 바꿀 때는 해당 매니페스트와 파일 해시 계약을 따른다. 출시된 의미 버전의 실행 내용을 조용히 덮어쓰지 않는다. 후보를 실제 GPU 결과 검증 없이 출시 상태로 승격하지 않는다.

배포 변경은 필요한 대상만 수행하고, 실행 중 작업을 먼저 확인한다. 배포 이력을 기록해 이전 배포로 되돌릴 수 있게 한다. GPU 생성 검증은 별도 승인 범위 안에서 수행한다.
