# 제2조 레퍼런스 관리

레퍼런스 영상은 "이런 느낌"을 실행 가능한 제작 규칙으로 바꾸는 재료다. 이 조는 레퍼런스를 모으고, 분석하고, 보관하고, 제작에 인용하는 방법을 정한다.

## 1. 구조

```text
저장소  docs/research/motion-references/
├─ README.md          전체 목록 + 태그로 찾기
├─ refs/<card-id>.md  영상 카드 (1편 = 1장, _TEMPLATE.md 양식)
├─ synthesis/         스타일 분류 · 제작 파이프라인 · 재사용 기법
└─ assets/            컨택트시트 등 가벼운 증거 이미지

F 드라이브  F:\modal-gui\references\
├─ <card-id>\                 카드 한 장의 원자료 (영상, 자막, 프레임)
└─ batch-<YYYY-MM-DD>-<주제>\  여러 편을 한 번에 분석한 원자료
```

- 텍스트와 판단은 저장소에, 무거운 원자료는 F 드라이브에 둔다.
- 카드 ID는 YouTube면 `<영상ID>-<짧은-이름>`, 그 밖에는 `<브랜드>-<짧은-이름>`이다. 한 번 정한 ID는 바꾸지 않는다.
- `assets/`에는 카드당 1–2장, 장당 1MB 이하 이미지만 둔다.

## 2. 수집

1. 원본을 내려받는다 (YouTube는 yt-dlp). 메타데이터와 자막을 함께 받는다.
2. 원자료를 곧바로 `F:\modal-gui\references\<card-id>\`에 둔다. `%TEMP%`에 둔 채로 카드를 완성하지 않는다.
3. 사용자가 첨부한 파일은 원본 파일명을 카드에 적고, 사본을 같은 폴더에 둔다.

## 3. 분석과 카드 작성

카드는 `refs/_TEMPLATE.md`의 모든 항목을 채운다. 비어 있는 항목은 "확인 안 함"이라고 쓴다.

증거 규칙:

- **분석 방법** 칸에는 실제로 한 것만 적는다. 메타데이터, 자막, 프레임, OCR, 장면 전환 검출, 오디오 분석 중에서 고른다.
- **관찰과 해석을 나눈다.** "7–11초에 컷 약 20회"는 관찰이다. "과장된 메시지와 맞물린다"는 해석이다.
- **AI 제작 여부**는 제작자가 밝혔거나 화면에서 확인된 경우에만 "확인됨"이라고 쓴다. AI 제품 광고와 AI로 만든 광고를 구분한다.
- 광고 속 성능, 가격, 수치 주장은 검증된 사실로 옮기지 않는다.
- 조회수처럼 변하는 값은 분석일을 붙인다.
- 자동자막의 고유명사는 화면이나 설명란과 대조한다.

카드를 쓰면 `README.md` 표에 한 줄을 추가한다. 새 스타일이나 기법이 나오면 `synthesis/`를 고친다. 결론이 바뀌지 않으면 `synthesis/`는 건드리지 않는다.

## 4. 태그

태그는 소문자 kebab-case로 쓴다. 만들기 전에 기존 태그를 먼저 찾아보고 재사용한다. 네 부류로 나눈다.

| 부류 | 예시 |
| --- | --- |
| 형식 | `9x16` `16x9` `loop` `low-fps` |
| 스타일 | `kinetic-typo` `paper-cutout` `y2k-pop` `3d-ui-card` |
| 기법 | `quiz-hook` `pun-naming` `input-to-result` `motif-callback` |
| 제작 경로 | `pipeline-video-gen` `pipeline-image-code` `pipeline-ai-ae` |

## 5. 제작에서 인용하기

- 브리프, 샷 계획, 프롬프트, 모션 명세에서 레퍼런스를 쓸 때는 카드 ID로 인용한다. 예: `ref: nepda-neop 0–2.5초 퀴즈 훅`.
- 한 작품을 통째로 따라 하지 않는다. 카드의 "가져올 것"에서 규칙을 골라 조합한다.
- 스튜디오 프로젝트에 레퍼런스를 붙일 때도 카드 ID를 함께 저장해, 결과물에서 근거 카드로 되짚을 수 있게 한다.

## 6. 권리와 사용 범위

- 레퍼런스 원자료는 분석과 내부 참고용이다. 원본 영상, 프레임, 음악, 로고를 결과물에 넣지 않는다.
- 생성 모델에 레퍼런스 이미지를 참조로 넣을 때는 스타일·구도 참조로만 쓰고, 타 브랜드의 로고, 캐릭터, 실존 인물을 그대로 재현하지 않는다.
- 원자료를 외부 서비스에 올려 분석해야 하면 사용자에게 먼저 확인한다.

## 7. 보관과 정리

- 원자료는 카드가 있는 동안 지우지 않는다. 카드를 폐기하면 카드 상단에 `폐기: YYYY-MM-DD, 이유`를 적고, 원자료는 `F:\modal-gui\references\_archive\`로 옮긴다.
- 다른 세션에서 만든 원자료는 그 세션이 끝난 뒤에 원위치를 정리한다. 진행 중이면 복사만 한다.
