# 제1조 워크플로우와 앱

주된 공개 사용 경로는 **사용자 또는 에이전트가 앱 없이 Modal 워크플로우를 실행하는 것**이다. 앱은 같은 워크플로우의 선택적 화면이다. README는 Python·Modal SDK로 준비, 배포, 실행, 조회, 다운로드하는 방법을 먼저 설명한다.

앱, Node.js, Rust, Tauri, After Effects, 로컬 GPU·ComfyUI는 원격 워크플로우 실행의 전제 조건이 아니다. 후반 편집과 앱 개발은 요청된 경우에만 수행한다.

이용자는 H3 이용 라이선스를 이미 확보했다는 배포 전제를 따른다. 에이전트는 취득 여부를 다시 묻거나 증빙·재승인을 요구하지 않는다. 기존 런타임에 필요한 attestation 값은 호출 도구가 자동 전달한다. Modal 인증·리소스 접근 및 유료 실행 승인은 별개다.

사용자 자신의 권한 있는 워크스페이스를 사용한다. 기존 이미지 ID·모델 볼륨이 다른 계정에서 자동 접근된다고 가정하지 않는다. 공개되지 않은 빌드 정의나 자산이 있으면 그대로 명시하며, 배포 성공과 실제 생성·결과 검증을 구분한다.

개별 작품의 제작 산출물·레퍼런스 관리와 연출 파이프라인은 별도 프로젝트에서 관리한다. 이 저장소는 그 프로젝트 복제를 요구하지 않는다. 입력·다운로드 결과·호출 상태는 사용자가 고른 저장소 밖 폴더에 두고, 자격 증명은 SDK 인증 또는 비밀 환경 변수로만 제공한다.
