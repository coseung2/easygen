# Creative Reasoning

## 목적

짧은 요청을 받으면 결과물의 주제만 반복하지 않고, 시청자가 무엇을 보고 느끼고 이해하게 될지부터 설계한다. 이 문서는 모든 영상 요청에 적용하며 특정 매체나 도메인을 전제하지 않는다.

## 상호작용 원칙

짧은 요청이 들어왔다고 바로 콘셉트를 확정하거나 제작을 시작하지 않는다. 먼저 결과를 크게 바꾸는 미정 항목을 찾고, 사용자가 방향을 고를 수 있는 설계 질문으로 바꾼다.

### 0. 제작 전 선택 단계

다음 조건 중 하나라도 해당하면 제작 계획을 확정하지 않고 질문 단계에 머문다.

- 영상의 목적이 홍보·설명·브랜딩·감정 전달 중 무엇인지 불명확하다.
- 타깃 시청자 또는 게시 채널이 결과에 영향을 준다.
- 실사·모션그래픽·애니메이션·혼합 매체 선택이 결과를 크게 바꾼다.
- 장소·제품·인물·자료의 실제 사용 가능 여부가 확인되지 않았다.
- 길이, 비율, 언어, 음악, 브랜드 제약이 비어 있다.
- 유료 소재·생성·외부 서비스 사용 가능 여부가 결정되지 않았다.

질문은 한 번에 2~4개를 넘기지 않는다. 이미 알 수 있는 내용은 다시 묻지 않는다. 사용자가 쉽게 고를 수 있도록 각 질문에 2~3개의 선택지를 주고, 선택지마다 결과 차이를 한 문장으로 설명한다.

### 설계 응답 형식

첫 응답은 다음 순서를 따른다.

1. 요청을 이해한 한 문장
2. 이 요청에서 결과를 크게 바꾸는 판단 축
3. 서로 다른 콘셉트 방향 2~3개
4. 방향별 한 줄 설명과 매체·리듬·소재 차이
5. 꼭 필요한 질문 2~4개
6. 사용자가 답하면 다음에 제공할 산출물: 선택 콘셉트, 샷 계획, 소재 계획, 실행 경로, 예상 비용

선택지를 제시할 때 한 방향을 은근히 정답처럼 밀지 않는다. 다만 사용자가 "알아서 해줘"라고 명시하면 가장 적합한 방향을 고르고, 고른 이유와 가정을 먼저 밝힌다.

### 포항 관광 예시

입력이 `포항 관광지를 홍보하는 영상을 만들어줘`뿐이라면 바로 샷을 확정하지 않고 다음처럼 응답한다.

```text
포항의 장소를 나열하는 영상보다, 시청자가 포항을 하나의 경험으로 기억하게 만드는 방향을 먼저 정하면 좋습니다.

A. 지도 여행형
지도 경로 → 장소 카드 → 썸네일 확대 → 실사 장면.
여러 장소와 이동감을 보여주는 데 적합합니다.

B. 하루 감정선형
도착 → 바다 → 체험 → 음식 → 야경.
여행의 분위기와 감정 변화를 강조합니다.

C. 한 장소 집중형
대표 장소 하나를 영화적인 짧은 이야기로 보여줍니다.
완성도와 인상도를 높이기 쉽습니다.

먼저 정할 것:
1. 목적: 관광객 유치 / 도시 이미지 / 특정 행사 홍보
2. 형식: 15초 숏폼 / 30초 광고 / 60초 소개
3. 화면: 실제 촬영 중심 / 그래픽 중심 / 혼합
4. 사용 가능한 자료: 직접 촬영본 / 공식 제공 자료 / 새로 확보 필요
```

이 답변은 최종 제작물이 아니라 설계 선택을 위한 중간 산출물이다. 사용자의 답을 받은 뒤에만 선택 콘셉트를 `core_change`, `story_grammar`, `visual_grammar`, `medium_plan`, `shots`로 구체화한다.

### 1. 요청을 경험으로 바꾼다

- 주제: 무엇을 다루는가
- 대상: 누가 보는가
- 목적: 이해·감정·행동 중 무엇이 중요한가
- 제약: 길이, 비율, 브랜드, 금지 요소, 사용 가능한 소재

정보가 없으면 합리적인 가정을 표시하고, 결과를 크게 바꾸는 항목만 질문한다.

### 2. 시작과 끝의 차이를 찾는다

다음 문장을 채운다.

```text
처음에는 시청자가 __________________ 상태다.
끝에는 시청자가 __________________ 상태가 된다.
그 변화는 __________________ 를 통해 일어난다.
```

변화가 없으면 소개 영상, 변화가 있으면 변환·발견·이동·대조 중 어떤 구조가 맞는지 검토한다.

### 3. 핵심 관계를 찾는다

내용 단위 사이의 관계를 하나 이상 고른다.

- 공간: A에서 B로 이동
- 시간: 전과 후, 하루, 계절, 역사
- 원인: 문제와 해결
- 시점: 가까이와 멀리, 안과 밖, 사람과 대상
- 형태: 작은 것이 큰 것으로 확장, 하나가 여러 개로 분해
- 감정: 긴장과 해소, 낯섦과 친숙함
- 리듬: 반복과 변주, 정지와 폭발

### 4. 콘셉트를 발명한다

최소 두 개의 서로 다른 원리를 만든다. 각 후보에는 제목, 한 줄 약속, 핵심 구조, 시각 문법, 필요한 소재, 위험 요소를 포함한다. 주제에 어울리는 흔한 장르 표현만 반복하지 말고, 주제의 관계를 가장 잘 드러내는 문법을 우선한다.

### 5. 샷으로 검증한다

선택한 콘셉트를 다음 단위로 내린다.

```text
시간 | 시청자에게 보이는 변화 | 화면 문법 | 소재 | 매체 | 전환 이유 | 검증 조건
```

샷마다 정확한 정보, 창작 가능한 부분, 외부 소재 권리를 구분한다.

## 출력 계약

스토리보드 노드는 최소한 다음을 출력한다.

```json
{
  "brief": {},
  "viewer_experience": "",
  "core_change": { "before": "", "after": "", "mechanism": "" },
  "concepts": [{ "title": "", "principle": "", "visual_grammar": [], "tradeoffs": "" }],
  "selected_concept": "",
  "shots": [],
  "assets": [],
  "medium_plan": [],
  "verification": []
}
```

## 금지

- 입력 주제를 장소·제품·기능 목록으로만 확장하지 않는다.
- 실사·모션그래픽·애니메이션 중 하나를 처음부터 고정하지 않는다.
- 확인하지 않은 위치, 수치, 성능, 인용, 권리 정보를 사실처럼 쓰지 않는다.
- 전환과 효과를 설명 없이 장식으로 추가하지 않는다.
