# 범용 창작 추론 체계

이 문서는 입력 주제나 제작 매체가 정해지지 않은 영상 요청을 콘셉트와 실행 가능한 샷 계획으로 바꾸는 공통 규칙이다. 관광·제품·교육·브랜드·추상 주제는 이 체계의 입력 사례일 뿐이며, 특정 장르의 기본값이 아니다.

## 문서 순서

1. `creative-reasoning.md`가 요청에서 시청자 경험과 핵심 변화를 추출한다.
2. `story-grammars.md`가 내용의 관계에 맞는 이야기 구조를 고른다.
3. `visual-invention-rules.md`가 추상적인 의미를 화면 문법으로 바꾼다.
4. `medium-translation.md`가 같은 문법을 실사·모션그래픽·애니메이션·혼합 방식으로 번역한다.
5. `transition-grammar.md`와 `rhythm-and-sound.md`가 장면 사이의 시간적 연결을 설계한다.
6. 그 결과를 기존 헌법의 레퍼런스·실행 경로·버전 규칙에 넘긴다.

콘셉트·톤·음악·전환 방향은 [approved-directions.md](approved-directions.md)의 승인된 항목만 고정값으로 쓰고, 나머지는 요청마다 새로 추천한다.

도메인별 문서는 이 과정을 대체하지 않고 사실 검증, 관습, 금지사항을 보충한다.

## 핵심 원칙

- 주제를 시각화하기 전에 시청자에게 일어날 변화를 정의한다.
- 장면을 나열하지 않고 장면 사이의 관계를 만든다.
- 전환은 장식이 아니라 의미가 이동하는 방식이다.
- 매체는 먼저 고정하지 않는다. 샷의 목적에 맞춰 고른다.
- 모델의 자유로운 발상과 검증이 필요한 사실을 분리한다.
- 콘셉트는 하나를 즉시 확정하지 않고 서로 다른 원리의 후보를 비교한다.
