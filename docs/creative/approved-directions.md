# 승인된 방향

사용자가 합격시킨 완성본(`verdict.md`)에서 쓴 방향만 적는다. 계획 단계의 제안, 고르지 않은 후보, 합격 전 버전은 적지 않는다. 쓰는 법은 [creative-reasoning.md](creative-reasoning.md) "방향 후보를 만드는 법"에 있다.

여기에 없는 항목은 AI가 요청마다 어울리는 방향을 새로 추천한다. 목록이 비어 있는 항목은 모두 추천으로 채운다.

형식: `방향 — 핵심 규칙 · 출처 · 승인일 · 조건`
