# Story Grammars

이야기 구조는 장르가 아니라 내용 단위 사이의 관계로 선택한다.

| 구조 | 질문 | 기본 동작 |
|---|---|---|
| 이동 | 무엇이 어디로 이동하는가? | 경로, 카메라 이동, 시점 이동 |
| 발견 | 무엇이 아직 보이지 않는가? | 가림, 단계적 공개, 확대, 레이어 해체 |
| 변환 | 무엇이 무엇으로 바뀌는가? | 매치 컷, 형태 변형, 전후 비교 |
| 충돌 | 어떤 두 힘이나 관점이 부딪히는가? | 대비, 분할 화면, 리듬 충돌 |
| 축적 | 작은 요소가 어떻게 커지는가? | 반복, 조립, 콜라주, 데이터 누적 |
| 반복·변주 | 같은 규칙이 어떻게 달라지는가? | 루프, 패턴, 템포 변화 |
| 시점 전환 | 보는 위치가 바뀌면 무엇이 달라지는가? | 매크로/와이드, 주관/객관, 현실/상상 |
| 해소 | 어떤 질문이 끝에서 해결되는가? | 문제 제시, 지연, 공개, 여운 |

하나만 고르지 않아도 된다. 주 구조 하나와 보조 구조 하나를 선택하고, 두 구조가 실제 샷에서 어떻게 결합되는지 설명한다.
