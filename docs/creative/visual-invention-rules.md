# Visual Invention Rules

추상적인 의도를 화면에서 관찰 가능한 규칙으로 바꾼다.

| 의도 | 먼저 검토할 화면 문법 |
|---|---|
| 연결 | 선, 경로, 매치 컷, 이어지는 움직임 |
| 확장 | 줌아웃, 프레임 확장, 작은 디테일에서 공간 공개 |
| 축소 | 크롭, 압축, 요소 제거, 좁아지는 시야 |
| 변화 | 같은 구도 유지, 내용·색·질감만 변환 |
| 복잡성 해소 | 레이어 분해, 순차 공개, 그룹화, 지도·노드 |
| 긴장 | 제한된 프레임, 불규칙한 리듬, 충돌하는 방향 |
| 해소 | 정렬, 여백, 안정된 구도, 긴 호흡 |
| 속도 | 컷 길이, 카메라 속도, 반복 간격, 사운드 밀도 |
| 기억 | 반복되는 색·형태·소리·구도 |
| 낯섦 | 익숙한 요소의 크기·맥락·재질 전환 |

선택한 문법은 모든 샷에 무작정 적용하지 않는다. 최소 세 번 반복하거나, 시작·중간·끝에서 변주해 하나의 시각적 규칙으로 인식되게 한다.
