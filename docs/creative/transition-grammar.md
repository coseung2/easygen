# Transition Grammar

전환은 다음 장면으로 넘어가는 기능과 앞뒤 의미를 연결하는 기능을 동시에 가져야 한다.

| 앞 장면과 다음 장면의 관계 | 전환 후보 |
|---|---|
| 같은 형태 | 매치 컷, 형태 변형 |
| 같은 방향 | 움직임 이어붙이기, 휩 팬 |
| 같은 색·빛 | 색면 리빌, 노출 전환 |
| 같은 소리 | J 컷, L 컷, 사운드 브리지 |
| 같은 의미 | 오브젝트·행동 반복 |
| 대비되는 의미 | 하드 컷, 정지, 화면 분할 |
| 지도와 실제 공간 | 경로 이동, 썸네일 확대, 좌표 리빌 |
| 정보와 감정 | 데이터가 이미지·행동으로 변환 |

전환 계획에는 `from`, `to`, `shared_property`, `transition`, `why`를 적는다. 공유 속성이 없으면 효과를 추가하지 말고, 장면 사이의 관계를 다시 설계한다.
