범위: 복사된 `lab/experiments/`의 **9개 실험**과 `lab/series-notes/`를 읽기 전용으로 분류했다. 이는 공개 후보의 **선별표**이지 이식·설치·재렌더 성공 보고가 아니다. `MODAL_GUI_DATA_ROOT`는 각 복제자가 설정하는 저장소 밖 미디어 루트다. 아래의 `lab/...`는 저장소 상대 경로, `DATA/lab/...`와 `DATA/series/...`는 그 루트 상대 경로를 뜻한다. 원본 매체·모델·음악·프로젝트는 자동으로 따라오지 않는다. 기록의 `rendered`/`verified`는 과거 작업 기록이며 새 복제 환경 검증이나 사용자 승인과 다르다.

## 튜링 v2–v7: 편집 원본과 빌드의 역할

`build*.jsx`는 AE에서 컴프를 **새로 구성하고 `.aep`를 저장하는 빌더**다. `.aep`는 사람이 수정·재연결할 수 있는 편집 프로젝트이고, `.jsx`나 MP4로 대체되지 않는다. `render.py`는 기존 `.aep`를 `aerender`로 렌더하고 FFmpeg로 인코딩한다. 각 판의 `.aep`는 원본 위치/푸티지 링크를 다시 연결하고 라이선스·크기를 점검한 후 외부 데이터로 보존할 것. 공개 Git에 무조건 포함하지 않는다. 스크립트의 개인 경로·열린 프로젝트 허용 목록을 이식 가능하게 바꾸기 전 AE 실행은 안전하지 않다.

## 이식 게이트

1. 텍스트/작은 코드만 선택적으로 검토한다. 미검토 `lab/experiments`·`lab/series-notes` 전체 복사, 로그·HTML·브라우저 덤프·원본 매체·자격 정보 공개는 보류한다. 절대 경로를 `MODAL_GUI_DATA_ROOT` 및 저장소 상대 경로로 바꾸고 실행 ID·개인/민감한 원문을 정제한다.
2. 각 엔트리포인트의 외부 파일을 명시한 manifest(상대 경로, 크기·해시, 권리, 취득/생성 절차, 폰트/모델의 정확한 출처·버전)를 별도로 작성한다. 확장자만 맞는 대체품은 재현 조건이 아니다. 비상업 라이선스와 표준 YouTube 사용권, 민감한 가족 미디어는 공개 자료와 분리한다.
3. 로컬 정적 점검 → 허가된 샘플의 보드/중간 이미지 생성 → FFmpeg/AE 재렌더·시청각 검수 → 승인된 경우에만 유료/라이브 H3·YuE2 테스트 순으로 검증한다. 현재 이 문서는 코드 실행, AE 가져오기, 클라우드 배포, 비용 확인을 수행하지 않았다.
