# moodboard

## 1.0 — candidate (2026-09-28)

- 사용자 지시로 제정: "무드보드는 현 주제를 영상으로 어떤 톤으로 만들지 컨셉 시안을 뽑는 것. 같은 장면 기준 6시안을 한 이미지에 그리드로." 턴마다 제각각이던 형식을 고정.
- 그리드: 칸 비율 = 영상 비율, 3열 × 2행, 라벨은 코드 렌더(생성 모델에 한글 금지). 셀 원본은 스타일 레퍼런스로 보존.
- 경로 필드(`kinetic`/`h3`/`mix`)로 시안 선택이 스토리보드의 실행 경로 결정과 이어지게 함.
- evals 없음. 출시 전 고정 입력 3개 이상 필요(제5조 §5-3).
- 승격 보류: 앱 무드보드 노드의 현재 포트(`refs` Image → `StyleGuide`)와 이 프롬프트의 출력(6시안 Json)이 다르다. 승격 시 계약 정합 필요(제5조 §3).

### 1.0 보강 (2026-09-28, 2차)

- 사용자 지시: "이미지로 뽑아두고 레퍼 삼게 하자."
- 레퍼 전달을 계약으로 추가: 레퍼런스는 라벨 없는 셀 원본, 합성 보드는 검토·기록용(생성 입력 금지). 출력 JSON에 `references[]`로 경로와 소비자를 기록.

### 1.0 보강 (2026-09-28, 3차)

- 사용자 지시: "6개를 생성하는게 아니라 한 이미지 안에 그리드로 배치."
- 생성 방식을 교체: 개별 셀 6장 생성 + 합성 → **생성 한 번으로 그리드 한 장**. 칸에는 숫자만, 한글은 코드 띠·표로.
- 레퍼 정의 갱신: 승인 시 같은 톤의 풀프레임 한 장(`boards/ref-<n>.png`)을 재생성해 그 파일을 레퍼로 삼는다(보드 절단 금지). 스키마 `cell` → `ref`.
- 승인 상태를 JSON에 남기도록 `approved` 필드 추가. 승인 직후 재생성이 실패하면 레퍼 없이 승인만 기록하고 보류한다(2026-09-28 이미지 한도 사고).
