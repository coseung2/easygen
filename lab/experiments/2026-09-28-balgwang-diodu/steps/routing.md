# routing

## 따른 지시

샷마다 정확성이 필요한지, 기존 소재 변형으로 되는지를 먼저 묻는다. 문구·발언·실제 경기 장면은 생성하지 않고 원본을 쓴다. 새 음악만 4단계로 올리고, 실행 전에 사용자 승인을 받는다.

## 출력

| 소재 | 단계 | 도구 | 비용 |
| --- | --- | --- | --- |
| 화면·글자·효과음·합성 | 1 | local-python (motionkit, sfx) | 0 |
| 경기·몽타주 소재 | 1 | yt-dlp 2026.08.19, ffmpeg | 0 |
| 누끼 | 1 | rembg bria-rmbg (비상업) | 0 |
| 사진 | 1 | Wikimedia Commons API | 0 |
| 음악 | 4 | Modal yue2-music, 1회 호출 | 실제 청구액 미확인, L40S 77초 |

## 사용자 수정

- GPT 이미지로 잘린 머리를 복원하자는 제안이 있었지만, 실제 프레임에서 머리 전체가 보이는 장면을 찾아 생성 없이 해결.
