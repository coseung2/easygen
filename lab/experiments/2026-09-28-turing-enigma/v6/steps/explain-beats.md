# explain-beats (v5 → v6)

- 입력: v5 영상, 사용자 질문("불가능한 매칭을 지워 찾는다는 뜻?"), 요청(설명을 녹이되 길어져도 됨, 영어 후킹을 선과 연결, 다이얼→알파벳 모프).
- 지시: 설명은 문장보다 그래픽으로. 각 설명 장면은 앞 장면의 요소에서 나온다(배선은 로터 안, 체크리스트는 통과한 대응선, 후보는 멈춘 다이얼, O는 정답 다이얼).
- 사실 보정: 에니그마(암호기)와 해독팀(연합군)을 구분. Bombe의 정지 = 후보, 사람이 확인. 17,576은 로터 순서 하나의 시작 위치 수.
- 출력: build_v6.jsx(_helpers.txt + _body.txt 합본), prepare_audio.py(v6 타이밍).
- 승격 후보: "설명 장면 = 직전 장면 요소의 재배치" 규칙을 스토리보드 노드 프롬프트의 체크 항목으로.
