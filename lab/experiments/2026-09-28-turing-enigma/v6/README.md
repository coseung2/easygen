# Enigma V6

상태: 완성본, 사용자 평가 대기. 1080×1920 · 30fps · 72.5초 · 내레이션 없음 · 외부 생성 호출 0회.

## 구성

v5 문법 위에 설명 장면과 영어 훅을 얹었다. 추가 내용은 DESIGN.md 끝의 "V6 추가" 표.

A→A 화살표 → 틈에서 `IS NEVER` 펼침 → 로터 링과 반사 배선(A→K, 자기 자신으로 가는 선 없음) → 빈틈 줌 → 날씨 보고와 WETTER → 모순 2번, 통과 1번 → 통과한 짝 6개가 체크리스트 → 다이얼 2개 시범 탈락 → 가속 탈락 17,576 → 3 → 정지 → 사람이 후보 3개를 풀어 봄(2개 실패) → 정답 다이얼이 U-BOOT의 O가 됨 → 좌표 → 해도, 항로 변경 → 항로가 화살표로, `IS NEVER` 회수.

## 검수

- ffprobe: 1080×1920, 30fps, 72.5초, AAC. 전체 디코딩 오류 0건.
- 1fps 컨택트시트 72프레임, MCP 프레임 렌더 19장 확인.
- 오디오: 통합 음량 -15.7 LUFS. 정지 구간(42–44.3초) 평균 -51dB.
- 하지 못한 것: 실제 휴대전화 재생, 주관적 청취 검수.
