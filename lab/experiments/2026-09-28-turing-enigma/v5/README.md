# Enigma V5

상태: 완성본, 사용자 평가 대기. 1080×1920 · 30fps · 60초 · 내레이션 없음 · 외부 생성 호출 0회.

[영상](enigma-v5.mp4) · [설계](DESIGN.md) · [컨택트시트 0–30초](qa-contact-1.jpg) · [30–60초](qa-contact-2.jpg)

## 구성

마스터 컴프 하나(`ENIGMA / V5 MASTER`)에서 선 하나가 장면을 넘어 살아남아 모양을 바꾼다.

A→A 화살표(끊어짐) → 로터 링(26칸 중 빈 칸 하나) → 빈틈 속으로 줌 → 암호문/예상 문구 레일(모순 2번, 통과 1번) → 통과한 대응선 6개가 Bombe 바늘 → 다이얼 42개 탈락, 카운터 17,576 → 1 → 정지(음악도 끊김) → 바늘에서 내려온 선이 암호문을 해독 → 좌표가 해도 위 U-보트 위치 → 새 항로(라임) → 항로가 곧게 펴져 첫 화살표로.

## 검수

- ffprobe: 1080×1920, 30fps, 60.0초, AAC 오디오. 전체 디코딩 오류 0건.
- 1fps 컨택트시트 60프레임, MCP 프레임 렌더 21장 확인. 1차에서 왼쪽 정렬 라벨이 잘린 것과 줌 전환의 과대 글자를 고쳤다.
- 오디오: 통합 음량 -15.5 LUFS. 정지 구간(33.2–35.6초) 평균 -60dB.
- 하지 못한 것: 실제 휴대전화 재생, 주관적 청취 검수.
