# storyboard (초안, 승인 대기)

## 따른 지시

선택된 방향을 초 단위 샷으로 내린다. 샷마다 시청자에게 보이는 변화, 전환의 공유 속성, 실행 단계(제4조 §2), 정확해야 하는 부분을 적는다. 지명·문구는 생성 모델에 쓰게 하지 않고 코드로 얹는다. 실제 장소를 생성 영상으로 대신하지 않는다.

## 입력 (사용자 결정)

- 까멜리아 = 구룡포 일본인가옥거리 (사용자 확인)
- 지도는 전부 이미지 생성, 자동차와 이동은 코드
- 오해 풀기를 앞 훅으로
- 톤 발랄·웃김 (승인됨)

## 가정

- 9:16, 30초, 30fps (장소 6곳이라 20초로는 부족)
- 지명 라벨은 코드로 얹음 (생성 이미지의 한글은 틀릴 수 있음)
- 지도 생성 시 실제 해안선·핀 가이드 이미지를 참조로 넣어 위치 왜곡을 줄임

## 출력

| 시간 | 화면 | 전환 공유 속성 | 단계 |
| --- | --- | --- | --- |
| 0–2.5 | "포항 하면… 철?" 회색 공장 → 빨간 줄 "철만 있는 줄 알았지?" | 회색 → 지도 색으로 채도 전환 | 1 코드 |
| 2.5–3.5 | 삽화 지도 공개, 북쪽 이가리에 자동차 등장 | 같은 화면이 줌아웃 | 3 지도 / 1 차·카메라 |
| 3.5–27.5 | 장소 6곳 × 4초: 주행 1.2 → 핀 도착·카드 0.5 → 카드 확대 0.5 → 실사 1.5 → 카드로 복귀 0.3 | 카드 테두리 = 실사 프레임 | 1 + 실사 소스 |
| 27.5–30 | 전체 경로 줌아웃, "생각보다, 포항" | 경로 선 전체 | 1 |

장소 순서(북→남): 이가리 닻전망대, 곤륜산, 스페이스워크, 영일대, 호미곶, 구룡포 일본인가옥거리.
